# Sorbetti

Questa directory contiene tutte le ricette di sorbetti (base acqua + zuccheri + frutta, senza latte/panna).

## Categorie incluse:
- Sorbetti di frutta
- Sorbetti agli agrumi
- Sorbetti alle erbe e spezie
- Sorbetti alcolici
- Sorbetti salati

## Struttura file:
- `[Nome]_Ricetta.html` - Ricetta completa con ingredienti e procedimento
- `[Nome]_Simulazione.html` - Simulazione sensoriale e note tecniche
