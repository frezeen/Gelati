# Gelati alla Frutta

Questa directory contiene tutte le ricette di gelati con frutta fresca (base latte/panna + frutta).

## Categorie incluse:
- Frutti di bosco (fragola, lampone, mirtillo)
- Agrumi (limone, arancia, mandarino)
- Frutta estiva (pesca, albicocca, melone)
- Frutta esotica (mango, passion fruit, cocco)
- Frutta autunnale (pera, mela, cachi)

## Struttura file:
- `[Nome]_Ricetta.html` - Ricetta completa con ingredienti e procedimento
- `[Nome]_Simulazione.html` - Simulazione sensoriale e note tecniche
