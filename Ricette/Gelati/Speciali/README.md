# Gelati Speciali

Questa directory contiene tutte le ricette di gelati con ingredienti particolari o tecniche speciali.

## Categorie incluse:
- Gelati alcolici
- Gelati salati
- Gelati alle spezie
- Gelati vegani
- Gelati senza zucchero
- Gelati con ingredienti inusuali

## Struttura file:
- `[Nome]_Ricetta.html` - Ricetta completa con ingredienti e procedimento
- `[Nome]_Simulazione.html` - Simulazione sensoriale e note tecniche
