# Gelati alle Creme

Questa directory contiene tutte le ricette di gelati a base crema (latte + panna + aromi).

## Categorie incluse:
- Vaniglia e varianti
- Nocciola e frutta secca
- Pistacchio
- Caffè e varianti
- Creme composite (Zuppa Inglese, Tiramisù, ecc.)
- Creme aromatizzate

## Struttura file:
- `[Nome]_Ricetta.html` - Ricetta completa con ingredienti e procedimento
- `[Nome]_Simulazione.html` - Simulazione sensoriale e note tecniche

I file sono collegati tra loro per navigazione bidirezionale.
