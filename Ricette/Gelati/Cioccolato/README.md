# Gelati al Cioccolato

Questa directory contiene tutte le ricette di gelati a base cioccolato e cacao.

## Categorie incluse:
- Cioccolato fondente (varie percentuali)
- Cioccolato al latte
- Cioccolato bianco
- Cacao amaro
- Varianti con nocciole, spezie, liquori

## Struttura file:
- `[Nome]_Ricetta.html` - Ricetta completa con ingredienti e procedimento
- `[Nome]_Simulazione.html` - Simulazione sensoriale e note tecniche
